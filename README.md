## 📖 Visão Geral

Extensão para Google Chrome (Manifest V3) que permite capturar a tela inteira, áreas selecionadas ou elementos visuais com ferramentas de anotação, edição em tempo real e privacidade total.

Parte integrante do ecossistema de soluções e sistemas web de alta performance da **[4U.IA.BR](https://4u.ia.br)**.

---

## ✨ Principais Recursos

- Captura de tela completa, aba ativa ou área livre selecionada
- Editor visual embutido com setas, caixas de texto, desfoque e destaques
- Gravação de tela e exportação rápida em alta resolução
- Processamento 100% no cliente sem telemetria ou envio de dados externos

## 🚀 Como Instalar e Testar no Google Chrome / Chromium

1. Clone este repositório ou baixe o código-fonte:
   ```bash
   git clone git@github.com:4u-Labs/printscreencapture.git
   ```
2. Abra o Google Chrome ou qualquer navegador baseado em Chromium (Brave, Edge, Vivaldi).
3. Acesse a URL: `chrome://extensions/`
4. No canto superior direito, ative a chave **Modo do desenvolvedor**.
5. No canto superior esquerdo, clique no botão **Carregar sem compactação** (*Load unpacked*).
6. Selecione a pasta onde o repositório foi clonado.
7. A extensão estará imediatamente ativa e pronta para uso!
